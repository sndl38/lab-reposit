# Лабораторные работы

Дисциплина: **Технологии и методы программирования**

Вариант: **1**  
Объект: **Доходы**

Работы выполнены на языке **Python**.

## Описание варианта

В рамках лабораторных работ реализуется программа для работы с объектами типа **«Доходы»**.

Объект содержит следующие свойства:

- дата;
- источник дохода;
- сумма.

Пример объекта:

```text
Доходы 2024.03.28 "Зарплата" 50000
```

## Лабораторная работа 1

В первой лабораторной работе реализована программа, которая формирует программный объект на основании его описания в виде текстовой строки.

Программа считывает строку, разбивает её на отдельные элементы, преобразует дату и сумму к нужным типам данных, после чего создаёт объект `Income`.

Пример входных данных:

```text
Доходы 2024.03.28 "Зарплата" 50000
```

Пример результата работы программы:

```text
Сформирован объект:
Дата: 2024-03-28
Источник: Зарплата
Сумма: 50000
```

Основные элементы программы:

- класс `Income`;
- функция разбора строки;
- преобразование даты;
- преобразование суммы в целое число;
- вывод созданного объекта на экран.

## Лабораторная работа 2

Во второй лабораторной работе программа из первой работы была доработана.

Добавлено чтение исходных данных из файла `data.txt`. В каждой строке файла находится описание одного объекта. Программа считывает объекты в список и отображает их в оконном интерфейсе.

Оконный интерфейс реализован с использованием библиотеки `tkinter`.

Реализованы следующие возможности:

- отображение списка доходов в таблице;
- добавление нового дохода через поля ввода;
- удаление выбранного дохода из таблицы.

Основные элементы программы:

- класс `Income`;
- функция `parse_income`;
- функция чтения данных из файла;
- оконный интерфейс;
- таблица для отображения объектов;
- кнопки добавления, удаления и загрузки данных.

## Лабораторная работа 3

В третьей лабораторной работе программа была доработана в части структуры кода и обработки исключительных ситуаций.

Программа разделена на **модель** и **вид**:

- модель отвечает за хранение данных и работу с объектами;
- вид отвечает за оконный интерфейс.

Добавлена обработка некорректных строк. Если строка в файле содержит ошибку, программа не завершает работу, а пропускает эту строку и записывает информацию о ней в файл `errors.log`.

Примеры некорректных строк:

```text

Расходы 2024.05.02 "Не тот тип" 500
Доходы 2024.05.03 "Ошибка суммы" пятьсот
Доходы 2024.05.04 Без кавычек 700
```

Основные элементы программы:

- класс `Income`;
- класс `IncomeParser`;
- класс `IncomeModel`;
- класс `IncomeView`;
- собственное исключение `IncomeParseError`;
- логирование ошибок в файл `errors.log`;
- модульные тесты для модели;
- UML-диаграмма классов.

Для проверки корректности работы модели были разработаны модульные тесты с использованием библиотеки `unittest`.

## Лабораторная работа 4

В четвёртой лабораторной работе программа была доработана добавлением обработки файла команд.

Команды применяются к уже загруженным данным и изменяют текущее состояние списка доходов. После выполнения команд данные обновляются в таблице.

Поддерживаются команды:

```text
ADD <данные>
REM <условие>
SAVE <filename>
```

Назначение команд:

- `ADD` — добавляет новый объект;
- `REM` — удаляет объекты, соответствующие условию;
- `SAVE` — сохраняет текущее состояние данных в файл.

Пример файла команд:

```text
ADD Доходы;2024.06.01;Подарок;3000
ADD Доходы;2024.06.05;Фриланс;18000
REM amount < 5000
SAVE result.txt
```

После выполнения этих команд программа добавляет новые доходы, удаляет доходы с суммой меньше `5000` и сохраняет результат в файл `result.txt`.

Основные элементы программы:

- класс `Income`;
- класс `IncomeParser`;
- класс `IncomeModel`;
- класс `IncomeView`;
- класс `CommandProcessor`;
- собственные исключения;
- обработка команд `ADD`, `REM`, `SAVE`;
- сохранение данных в файл;
- модульные тесты для модели и обработчика команд;
- UML-диаграмма классов.

Для оценки качества тестирования использовался инструмент `coverage.py`.

Покрытие кода тестами составило:


## Запуск программы

Для запуска программы необходимо выполнить файл `main.py`.

```bash
python main.py
```

В Git Bash при использовании виртуального окружения:

```bash
./.venv/Scripts/python.exe main.py
```

## Запуск тестов

Для запуска модульных тестов:

```bash
python -m unittest discover
```

В Git Bash при использовании виртуального окружения:

```bash
./.venv/Scripts/python.exe -m unittest discover
```

## Проверка покрытия тестами

Установка `coverage.py`:

```bash
python -m pip install coverage
```

Запуск проверки покрытия:

```bash
python -m coverage run -m unittest discover
```

Вывод отчёта в консоли:

```bash
python -m coverage report
```

Создание HTML-отчёта:

```bash
python -m coverage html
```

После выполнения команды HTML-отчёт будет находиться в папке:

```text
htmlcov/
```
